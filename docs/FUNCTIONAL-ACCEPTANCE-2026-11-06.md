## 5. 结论

1. **手机端采集、报文映射、链路传输、接收端解析：全部正常**（22/22 输入项 + 250 pps 零丢包）。
2. **体感输入：可用**（传感器订阅、50 Hz 采样、叠加到右摇杆均已验证）；主观手感待人工确认。
3. **「用手机操控电脑玩游戏」当前不可用**，唯一原因是 ViGEmBus 驱动已被移除。装回便携包内 `可选驱动/ViGEmBusSetup_x64.msi`（876 KB，离线）并重启即可恢复；05:20 驱动在位时该项实测 7/7 通过。
4. **震动回传不可用**，属未实现项。
5. 多人（2P–4P）未验证：当前仅一台手机在线。

### 6.1 两处判定方法修正（重要，避免下次误报）

1. **GUIDE 必须用 `XInputGetStateEx` 读取**。标准导出 `XInputGetState` 对任何
   Xbox 360 手柄都不返回 `XINPUT_GAMEPAD_GUIDE`（0x0400），物理手柄同样如此。
   未公开导出 **ordinal 100** 才是会返回该位的接口：
   ```python
   xi = ctypes.WinDLL("xinput1_4.dll")
   xi_ex = xi[100]          # XInputGetStateEx
   ```
   用标准接口断言 GUIDE → 必然误报 FAIL。
2. **A 键首测失败属 adb 注入时序**：同一坐标连测 3 次，命中 `0x1000`。
   `input swipe x y x y 350` 的按下沿偶发丢失，重试即通过，非功能缺陷。
