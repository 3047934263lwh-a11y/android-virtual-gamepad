# 更新记录

## v1.1.4（2026-11-08）

### 手机端 · 后台保活（本次重点）

- **退到后台/锁屏不再断连**：会话期间启动前台服务（`connectedDevice` 类型，常驻通知显示连接状态与 pps），
  并持有 `PARTIAL_WAKE_LOCK` 与 Wi-Fi 低延迟锁。此前应用退到后台很快变成 cached 进程被系统冻结，
  250Hz 发送线程停摆，接收端 2 秒槽位超时即释放，表现为「一退后台就断开」。
- **后台也能自动重连**：`onPause` 不再取消看门狗与重连任务，重连路径上所有「必须在前台」的守卫已移除；
  回到前台时基准复位，不会把后台空档误判成故障。
- **冻结检测与说明**：看门狗空档超过 5 秒判定进程被系统挂起，回到前台立即重建链路，
  并弹一次说明（含跳转电池设置 / 应用详情的入口），不再出现「不知道为什么断」。
- **修复连接即被系统杀进程**：上一版在点击连接时会申请通知权限并弹电池优化对话框，
  系统弹窗让应用短暂进入后台，厂商权限组件会借此结束进程。现在连接路径不触发任何系统 UI，
  通知权限与电池白名单改由用户按需在系统中开启。
- 后台重连退避上限放宽到 30 秒，减少长时间挂后台的唤醒；无会话且退到后台时看门狗停拍。

### PC 接收端

- 版本号口径统一为 1.1.4（exe 文件属性、便携包名、随包 APK 名一致）。

### 便携包

- 随包 APK 与 Release 资产同版本，PC 端 exe 为 1.1.4。

## v1.1.3（2026-11-08）

### 手机端

- **连接状态初始化修正**：新增「会话」状态位。冷启动后、用户未点击连接开关前，状态栏稳定显示「未连接」，
  不再出现「连接中断，正在自动重连…」，也不会自行发起连接。
- **去掉开屏自动连接**：移除了「保存过 IP 就自动连」的隐式行为，连接一律由用户点击开关发起。
- **重连调度修复**：取消待执行的重连任务时同步复位排程标志，修复「断开/切换后链路不再自愈、
  界面长期停在正在自动重连」的问题。
- **布局槽位长按菜单改为 Material 3**：圆角弹窗 + 24dp 图标 + 文字按钮式列表项，
  提供「用当前布局覆盖此槽 / 重命名 / 清空此槽」；重命名对话框同步为 M3 样式。
- **输入法适配**：地址与端口输入框禁用「全屏编辑（抽取模式）」，
  横屏下点击输入框直接弹出常规/悬浮键盘并原位编辑。
- 前后台切换不再影响连接状态：切到后台再回来，会话与状态保持不变。

### PC 接收端

- 版本号口径统一为 1.1.3（窗口标题、exe 文件属性、便携包名、随包 APK 名一致）。

### 便携包

- 随包 APK 与 Release 资产同版本，PC 端 exe 为 1.1.3。
