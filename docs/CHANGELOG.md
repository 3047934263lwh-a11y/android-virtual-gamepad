# 更新记录

## v1.1.3（2026-11-08）

### 手机端

- **连接状态初始化修正**：新增「会话」状态位。冷启动后、用户未点击连接开关前，状态栏稳定显示「未连接」，
  不再出现「连接中断，正在自动重连…」，也不会自行发起连接。
- **去掉开屏自动连接**：移除了「保存过 IP 就自动连」的隐式行为，连接一律由用户点击开关发起。
- **重连调度修复**：取消待执行的重连任务时同步复位排程标志，修复「断开/切换后链路不再自愈、
  界面长期停在正在自动重连」的问题。
- **布局槽位长按菜单改为 Material 3**：圆角弹窗 + 24dp 图标 + 文字按钮式列表项，
  提供「用当前布局覆盖此槽 / 重命名 / 清空此槽」；重命名对话框同步为 M3 样式。
- **输入法适配**：地址与端口输入框禁用「全屏编辑（抽取模式）」，
  横屏下点击输入框直接弹出常规/悬浮键盘并原位编辑。
- 前后台切换不再影响连接状态：切到后台再回来，会话与状态保持不变。

### PC 接收端

- 版本号口径统一为 1.1.3（窗口标题、exe 文件属性、便携包名、随包 APK 名一致）。

### 便携包

- 随包 APK 与 Release 资产同版本，PC 端 exe 为 1.1.3。
